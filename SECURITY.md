# Reporting a security problem

Please do not disclose vulnerabilities, credentials, private URLs, or personal
data in a public issue or pull request.

Use [GitHub's private vulnerability reporting form](https://github.com/itsMattGuenther/Focusaurus/security/advisories/new)
for this repository. Describe the affected version, the impact, and the smallest
safe example needed to reproduce the problem. Do not attach another person's
browsing data or a working credential.

Focusaurus is maintained independently. We will review reports as availability
allows; there is no guaranteed response time or paid bug-bounty program.

The latest release and the current development branch are the focus of security
maintenance. A voluntary blocker can be disabled or a session can be ended by
its user; that expected behavior is not a security boundary.
