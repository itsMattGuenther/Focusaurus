# Contributing to Focusaurus

Thanks for helping make focus a little easier. Useful contributions include
bug reports, clearer wording, accessibility improvements, design feedback,
documentation, and code.

## Report a problem or suggest an idea

[Open an issue](https://github.com/itsMattGuenther/Focusaurus/issues/new/choose).
For a bug, include your browser/version, what you expected, what happened, and
simple steps we can use to reproduce it. A made-up example site or redacted
screenshot is usually enough. Do not include private URLs, passwords, settings
exports, or personal browsing history.

For security problems, follow [SECURITY.md](SECURITY.md) rather than posting
exploit details in a public issue.

## Make a change

1. For a substantial feature or redesign, start an issue so we can agree on
   scope before you spend time building it. Small fixes can go straight to a PR.
2. Fork the repository and create a branch for your change.
3. Follow the [developer guide](docs/DEVELOPMENT.md) to build and check it.
4. Keep the change focused. Explain the user problem, what changes, and how you
   checked it. Include screenshots for visual changes, with private details removed.

Tests should cover behavior that matters. For documentation-only changes,
check the wording and links; you do not need to run the full browser suite.

Focusaurus aims to stay private, approachable, and supportive. Changes should
respect keyboard navigation, readable contrast, reduced motion, and the user's
ability to end a session. Do not add tracking, remote code, or unnecessary
browser permissions.

Please be kind and constructive when discussing changes. We can disagree about
a design or implementation while treating each other with respect.
